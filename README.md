# 机组智能排班助手（路演演示版 · 示例数据）

纯 HTML/CSS/JS 单页应用，无构建、无外部依赖、完全离线。**直接双击 `index.html` 用浏览器打开即可**（推荐 Chrome / Edge）。
所有人员、任务均为程序生成的 **示例数据（SAMPLE）**，与真实人员、航班无关。

## 目录
```
index.html          页面入口
css/style.css       深蓝航空运控风格样式
js/core.js          核心：示例数据生成 / 规则 / 自动填人求解器 / 校验 / 指标 / 请假调配（浏览器与 Node 通用）
js/charts.js        自写轻量 SVG 图表
js/app.js           界面逻辑
test/test.js        Node 无界面测试：node test/test.js
screenshots/*.png   各主要视图截图（供 PPT）
```

## 功能
| 模块 | 说明 |
|---|---|
| 人员视图 | 甘特图：行=飞行员（员工号/姓名/级别/本月小时），列=2026年11月每天；任务条显示 D1..Dn 航线与时刻，如 `D1 成都-乌鲁木齐 08:00-12:20`，以及“机/副/三”机组；特殊机场红字；意向休息日、请假日以斜纹标示；悬停看详情，点击调整机组 |
| 任务视图 | 全部任务列表，可筛选 未满员/已满员/有违规/特殊机场，显示“始发站需血压测试仪”提醒 |
| 一键自动填人 | 启发式多轮求解（约 2–4 秒），含休息节奏偏好与备份编排，带进度与结果摘要 |
| 手工调整 | 点任务 → 每个岗位下拉框仅列合规候选（按本月小时升序，⚠ 标注占用意向休息日）；不合规人员逐人列出原因（时间冲突、休息不足、请假、超 70h、某航段无满足座位/特殊机场规则的组合、新机长缺教员等） |
| 校验报告 | 合规（各硬性规则违规数）、公平（各组工时区间/均值/标准差/基尼系数、每人工时柱状图）、合理（过夜、特殊机场暴露、夜航均衡、意向休息满足率）、覆盖率；节奏（任务天数分布、休息间隔分布、2–3 天占比、备份公平性） |
| 请假调配 | 选人 + 选日期 → 仅移出受影响任务中的该人，其他成员不动；按“低工时优先、不占意向休息日”找合规替补；显示前后对比和无法解决项及原因；可撤销 |
| 员工福利 | 每人 2 个意向休息日（示例已预填，可修改）；每日休息/请假人数按机长类、副驾驶分别限额（超限拒绝申报）；显示满足率 |
| 设置 | 最短休息、每日备份人数、每人每月最多备份天数、休息偏好权重、月小时上下限、同日休息上限、报到/退场时间、血压测试仪机场、机场特殊类别 |
| 导入导出 | 导出排班表（逐航段含机组）、人员工时、问题清单、人员/任务数据、JSON 备份（UTF-8 BOM，Excel 直接打开）；导入人员/任务 CSV（提供模板）与 JSON 备份 |
| 存储 | 浏览器 localStorage；顶部“重置示例数据”一键恢复 |

## 已实现规则
**岗位**：每个任务 = 机（机长类：新机长/机长/教员）+ 副（副驾驶 F1–F8）+ 三（任意级别）。三人制下，**每一航段**只需三人中存在一组“左座+右座”满足以下全部规则，第三人观察，各航段可换座。

**RE12 座位搭配（左座 → 允许右座）**
- SPIC：仅 TL/TB/TC
- US / J0 / J1 / 机长A / 机长B：F4–F8 及任何机长/教员
- J2 / J3：F3–F8 及任何机长/教员
- TL/TB/TC：任何人
- F1、F2：机组中须有教员

**新机长（SPIC/US/J0/机长A/机长B）**：机组中须有 TL 及以上教员（求解器在新机长任“机”位时自动安排教员为“三”）。

**特殊机场**（需本人授权，红字显示；左右座两人都须持该机场授权）
- 拉萨 ZULS：两人均 J3 及以上
- 丽江 ZPLJ / 西双版纳 ZPJH / 西昌 ZUXC / 西宁 ZLXN / 大连 ZYTL：J2/J3 + F6 以上，或教员 + F5 以上
- 一般高原：迪庆 ZPDQ / 稻城亚丁 ZUDC / 九寨 ZUJZ：J2/J3 + F5 以上，或教员 + F4 以上
- 赤峰 ZBCF：J2/J3/教员 + F4 以上
- 克拉玛依 ZWKM：左座 J1 及以上；茅台 ZUMT / 吕梁 ZBLL / 忻州 ZBXZ：左座 US 及以上（这两类只限级别，不需授权）
- 延吉 ZYYJ：无额外要求
- A321 航段：左座须 J2 及以上

**时间与工时**：同一人任务不重叠；两任务间（末段落地+30 分钟 → 下一任务首段起飞前 60 分钟）休息 ≥ 12h（可配）；请假日不排；月飞行小时（轮挡时间）30–70h 硬约束。

**血压测试仪机场**：部分本场/始发机场须配备血压测试仪。设置中勾选的机场作为始发站（出港）时，相关任务标记“需血压测试仪”（提醒级，示例为西安 ZLXY、乌鲁木齐 ZWWW；正式机场清单待确认，可在设置中随时调整）。数据字段为 `settings.bpTesterAirports`，旧版存档中的 `testerAirports` 会在加载时自动迁移。

**甘特图缩放与滚动**：人员视图右下角为浏览器式悬浮缩放控件「− 100% + ▾」：−/+ 按档位缩放（4%–160%，100% = 日视图 150px/天），点击百分比恢复 100%，▾ 菜单提供 日 / 3日 / 周 / 半月 / 整月·全局 预设；也可按住 Ctrl/⌘ 滚轮或触控板捏合缩放（以鼠标位置为中心）。“整月·全局”一屏显示全部飞行员与任务（行高、标签自动压缩，悬停查看详情）。甘特视口高度贴合窗口，底部横向滚动条常显（已用 ::-webkit-scrollbar 样式覆盖 macOS 默认隐藏的覆盖式滚动条），左侧姓名列固定，缩放控件不遮挡滚动条。

## 飞行节奏与备份（Standby）
- **示例任务**：以 3–4 天多日任务为主（约 80%），少量 1–2 天；每天 2–4 段（平均约 2.6 段/天），外站过夜，始终从 ZUUU 出发并回到 ZUUU。
- **示例人员结构（为节奏/工时可行而调整）**：教员 10（TC2/TB3/TL5）、J3 23、新机长 6、副驾驶 61（F8 2、F7 12、F6 11、F5 11、F4 7、F3 15、F2 2、F1 1）。原 J3 17 / 副驾驶 67 的结构下机长类是瓶颈（拉萨需两名 J3+、新机长需教员同组，额外占用机长类座位），无法在 70h 内把所有任务排满。
- **休息间隔偏好（软约束）**：两任务间空闲 2–3 天最优；0–1 天、4 天、5+ 天逐级加罚（扣除意向休息日/请假日后计算）。12h 最短休息仍为硬约束。权重可在设置中调整。
- **备份**：贴近实际——每人每月至多 1 天备份（多数人当月为 0），每天 1 人（机长类/副驾驶交替，新机长不单独担任），全月约 30 人日；备份日须前后一天均无飞行任务。其余空闲日均为正常休息（不再因“连续空闲”插入备份）。每日人数与每人上限可在设置中调整；旧存档中的备份参数加载时自动迁移。甘特图中以琥珀色“备份”格显示。
- **请假调配首选备份人员**：替补时优先选择任务首日处于备份的合规人员，调用后自动撤销其相应备份日。手工调整下拉框中以“★备份可调用”标注。

## 求解思路
1. 难度优先：含拉萨/特殊机场/A321 的任务先排，其余按时间顺序；
2. 每个任务从候选中组合“机/副/三”，逐航段验证合法性；评分 = 工时占比 + 休息间隔偏好代价 + 高低级副驾驶搭配 + 第三人优先副驾驶；
3. 意向休息日首轮严格遵守，确实排不满时才放宽（计入满足率）；
4. 局部搜索（单岗位替换）+ 交换搜索（高工时与低工时人员互换同岗位任务），同时考虑工时方差与休息间隔；
5. 释放“三”位上非必要的机长类人员给空缺任务，再补齐；剩余空缺尝试一步“置换链”；
6. 编排备份；
7. 以上整体做最多 5 轮随机扰动，取最优（硬违规 → 软违规 → 2–3 天休息占比 → 工时标准差）。浏览器中约 2–4 秒。

- 100 名飞行员、148 个任务（1天13 / 2天16 / 3天68 / 4天51），1895 任务飞行小时
- 满员率 100%；**硬性违规 0**；软性 0
- 月飞行小时：全员 45.7–66.3h，均值 56.8h，基尼 0.031
  - 教员 57.7–63.6（均 60.2，σ1.8）；机长 J3 58.1–63.4（均 60.2，σ1.3）；新机长 45.7–54.1（均 52.2，σ3.0）；副驾驶 53.1–66.3（均 55.5，σ2.4）
- 任务间休息：344 个间隔中 2天 133、3天 84、4天 38、0–1天 49、5+天 40；**2–3 天占 63.1%**，均值 2.8 天
- 备份：共 30 人日（每天 1 人）；30 人各 1 天、70 人 0 天（机长类 0–1，副驾驶 0–1）
- 意向休息日满足 200/200 = 100%
- 请假调配测试：J3 请假 3 天，影响 2 个任务，其中 1 个由当日备份人员顶替，调配后硬性违规 0
- 其他 5 个随机种子：全部 0 硬性违规、满员 100%，2–3 天休息占比 54–65%，副驾驶最低工时个别种子到 41h

## 假设与限制
- 工时目标约为机长类 ~60h、副驾驶 ~55h；新机长因必须与教员同组（教员占“三”位），工时偏低（~52h）。进一步提高总量（>1900h）时贪心+局部搜索开始出现 1–2 个任务机长类无人可排，故示例取 1880h 目标。
- 0–1 天休息间隔仍约占 14%，5+ 天约 12%（多为月初/月末或与请假相邻）；“2–3 天”为软目标。
- 备份日仅作为“占用一天、不计飞行小时”的值班，未建模备份时段与报到时限；备份规则按日粒度。
- 月小时下限按可用天数折算（有请假者按比例降低）。
- 工时按轮挡时间计算；未建模值勤期、累计疲劳等 CCAR-121 FTL 细则，最短休息为单一可配参数。
- 未建模机型资格以外的个人资质；F1 仅作“须有教员”处理。意向休息日 / 请假同日上限只在申报环节控制。
- 机场列表、航班号、时刻、授权均为示意数据。浏览器数据键为 crewRoster.v2（旧版本数据不会沿用）。
