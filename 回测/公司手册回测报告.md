## 1. A3 / EU.COM · 飞行时间 / 值勤 / 休息 / 备份

### 1.1 月飞行时间硬上限

| 项 | 内容 |
|---|---|
| 公司条款 | **3.6.4 2）（1）**（页码 **3-6-4**，修改号 07-00，日期 25/09/01）：「任一日历月,**100 小时**的飞行时间」 |
| 121-R8 | 121.487(b)(1) **100h** |
| 本 App | `hardMaxHours` 默认 **90**；文案已区分「设置值」与法规 100h |
| 结论 | ⚠ **90≠公司/法规**。公司明确 100h；**未改默认数值为 100**（保持更严可配上限）；文案改为标明「公司手册与法规均为 100h」 |

### 1.3 休息期定义与最短休息

| 项 | 内容 |
|---|---|
| 公司定义（附 1.1.27，页 **附 1-1-5**） | 「从机组成员到达适宜的住宿场所起，到为执行下一次任务离开适宜的住宿场所为止…值勤和…交通工具往来…不得计入休息期。」（与 R8 121.481(c)(9) 同义） |
| 公司主基地操作口径（**3.6.1 4）a**，页 **3-6-2**） | 「休息期应当于…发动机关车**后的 40 分钟**（15 分钟关车后离开机场时间+25 分钟航后车程时间）后开始，于…下次执行任务规定的**报到前 25 分钟前**截止。」 |
| 两 FDP 间最少休息（**3.6.10 4）**，页 **3-6-6**） | 「至少连续 **10** 个小时的休息期」 |
| 报到时刻（**3.6.1 3）a**，页 **3-6-1**） | 飞行机组：计划起飞前 **95** 分钟（国际/地区 **115**）；客舱 105/125；安全员 100/120 |
| FDP 终止 | 「最后一次飞机到位**发动机关车**时间」（非落地+30） |
| 121-R8 | 休息≥10h；FDP=报到→关车 |
| 本 App | `reportMin=60`（已改为默认 **95** 对齐公司国内飞行组）、`releaseMin=30`、`minRestH=12`：用「落地+30→下次报到」≥12h 近似 |
| 结论 | ⚠ 口径不同且 App 更严（12h vs 10h；路径时间模型简化）。**不是**「落地后+30到下次报到」的公司定义。 |

## 4. 本次对代码的最小修改

1. **文案**：月上限标明「**公司手册 EU.COM 3.6.4 与 CCAR-121.487 均为 100h**；本系统设置默认 90h（更严，可改）」；去掉易误解的「法规硬上限=90」图表标签。
2. **`reportMin` 默认 60→95**：对齐公司国内飞行组报到（3.6.1）；不改变 `minRestH=12` / `hardMaxHours=90` 数值。
3. **常量 `COM`**：记录手册修订号与关键公司数字，供 UI/测试引用。
4. **回归测试**：COM 常量、月上限文案含「公司」、`reportMin===95`。
5. **未做**：不把 90 改为 100；不实现 144h/48h、第5日、7日60h、月210h、主备份并入 FDP（需产品拍板）。
