## 4. 差距主因（按证据排序）

1. **目标函数不同**：引擎压公平（std/gini↓、工时带宽收窄）与节奏修复（gap34↑）；运控保留更大工时离散与更密的连飞/短间隔。
2. **同网 refill 仍几乎全换机组**：座位一致率 ~1%，说明差异主要在**派谁**，不是任务网形状。
3. **外中队/教员约束**：真表大量「新机长无教员」在引擎侧不可复现为同一外中队搭配，只能本池重排。
4. **FDP/休息建模**：段时刻为窗内比例切分；`softRest48H=60` 推动与真表不同的人选。
5. **非飞行占位**：引擎重派 standby/control/sim 密度（备份 67→102，模拟机 144→100，控班 38→15）；真表培训/假/控班来自运控计划。
6. **多种子 minDiff**：历史 UI 为「多套方案」强制 ≥40% 换人，会**主动放大与上套差异**，与贴真表目标相反。已改为单次生成、只保留最新一套。

## 5. 产品结论

- **模拟表格1** = 真实导入（保持）。
- **一键自动填人** = 独立生成器路径；方案区最多「真实表 + 最新生成」两套；不再堆积 5 套轮播。
- 请假补位的多方案逻辑未改。
