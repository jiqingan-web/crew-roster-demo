为排班办准备的能力矩阵

从自动编排到异常处置、规章对照与 AI 侧栏——覆盖月度排班与日常调配主线。

⚡

一键自动填人

多轮优化填满三人制座位，兼顾休息、资质与工时均衡；宁缺毋滥，不以违规飞行塞满。

🔄

请假调配 / 空洞换人

临时请假生成多套补位方案；空洞诊断区分数据问题与真实运力不足，应用后记入补位历史。

📋

校验报告与空洞诊断

硬/软违规分列，定位缺人任务；导入预检可跳过任务固有问题，强制指派可审计。

📊

运营看板

满员率、备份缺口、请假人日与每日空洞趋势一屏掌握，服务日清与月度复盘。

⏱

执勤 / 延误鲁棒

执勤期余量监控与 +30/+60 分延误压力；高风险日可生成预防性拆分换组方案。

🧪

压力回测三场景

设置页一键对比基线、多人同时请假、任务密度 +30%、特殊机场资质稀缺——不改 live 排班。

🤖

千问 AI 侧栏

纯前端对接 DashScope，Key 仅存本机；解读满员/违规/工时，给出请假调配思路。

✈

模拟机占位 · 帮扶规则

模拟机块提前占位、一键排班不覆盖；帮扶对象同任务机组至多一名，人员页可标记。

场景路径

为每一种排班痛点找到路径

不是另一张大表格，而是对应日常决策的可点击路径。

PATH 01

临时请假

选人 → 生成合规替补方案 → 预览工时前后 → 一键应用并留下补位痕迹。

PATH 02

资质瓶颈

特殊机场 / 座位搭配 RE12 约束进候选过滤；压力场景可模拟授权人数骤降。

PATH 03

工时公平

自动填人与同级转让倾向低工时；看板与校验报告暴露区间、标准差与高强度提示。

PATH 04

规章合规

表 A/B、休息与第 5 日口径写入硬规则；回测报告对照 R8 与公司手册可公开查阅。

合规对照
