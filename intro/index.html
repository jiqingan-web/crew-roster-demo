AUTOFILL

一键出草案。

整月逐格填太慢，约束一交叉就不敢说「过了」。

一键自动排班，在三人制座位、休息、资质等硬约束下生成可校验草案；宁缺毋滥。

演示盘 212 / 212 满员 · 硬违规 0

VALIDATE

违规，点一下就到。

规章靠口头提醒时，硬伤和软提醒搅在一起，只能事后翻账。

校验报告硬/软分列，点击条目定位到任务；三人制、特殊机场、新机长带教、帮扶≤1、第5日等进引擎。

基线硬违规 0 · lite 可复跑

LEAVE-REPAIR

请假，多方案比较。

临时请假靠群聊喊人，方案难并列，合规与影响说不清。

系统给出多套方案卡片，看合规灯再应用；补位写入痕迹，历史可撤销。

lite「请假调配」可走完全流程

DIAGNOSE

排不满，也说得清。

只知道「排不满」，分不清是表有问题、规则冲突，还是人真不够。

空洞诊断给出原因分类，并指向强制指派、换人链或自动纠错。

报错数量 → 下一步动作
