02 // DIFF

BEFORE / AFTER

从表格手工流，到规则运行时——同一套业务，两种体感。

BEFORE Excel / 旧排班系统
  • 填人手工逐格抠表，跨表对不上就靠眼力
  • 规章靠经验与口头提醒，违规定位靠事后翻账
  • 请假群里喊一声、电话串人，方案难并列比较
  • 回溯「当时为什么这么排」难还原，痕迹散落聊天记录
  • 压测不敢动 live 表；密度一涨只能硬扛
AFTER 本助手 · RUNTIME
  • 填人一键 AUTOFILL，三人制座位一次排满
  • 规章硬/软违规即时校验，可点击定位到任务
  • 请假多方案卡片 + 空洞诊断 + 合规灯
  • 回溯方案历史 / 补位痕迹可撤销、可对照
  • 压测三场景压力回测不改 live；千问侧栏解读

03 // MODULES

能力模块

像 IDE panel / ROM cartridge——点进 lite 即可跑通。

ROM01
AUTOFILL

一键填人

三人制座位一次排满；休息、资质、工时均衡；宁缺毋滥。

ROM02
LEAVE-REPAIR

请假补位

临时请假生成多套合规替补；应用后写入补位痕迹。

ROM03
VALIDATE

校验与空洞诊断

硬 / 软违规分列；区分数据问题与真实运力不足。

ROM04
OPS

运营看板

饱和度/韧性、今日运营、公平性基尼、延误韧性一屏掌握。

ROM05
STRESS

压力回测

基线 · 多人请假 · 密度+30% · 资质稀缺——不改 live 排班。

ROM06
QWEN

千问侧栏

纯前端 DashScope；Key 仅存本机；解读满员 / 违规 / 工时。

ROM07
SIM-HOLD

模拟机占位

模拟机块提前占位，避免与飞行任务冲突。

ROM08
BANGFU

帮扶规则

帮扶对象同任务机组至多一名；写进规则引擎。

04 // OPS-BOARD

运营看板能力

对照 lite「运营看板 / 执勤监控 / 设置」真实模块——不编造仓库里没有的图。

SAT / RESILI

饱和度 · 韧性度

已排小时 ÷ 容量、剩余可排 ÷ 容量；四象限（理想 / 低效 / 告警 / 危急）。可下钻分中队。

TODAY-OPS

今日运营

焦点日未满员任务、高 FDP 风险、待补位空洞、备份缺口（当日备份 vs 请假）；可复制 / 导出今日简报。

MONTH-BRIEF

月度简报口径

未满员、FDP 风险日、备份缺口人日、请假人日等——写入 briefText，随看板一键带出。

DUTY-MON

执勤监控

按实际/预计时刻滚动监控 FDP 余量；延误致余量告急时可生成多套合规换人方案。

DELAY ±30/60

延误鲁棒

设置页「延误鲁棒性检查」：每段 +30 / +60 分钟冲击，统计仍合规的处置空间。

FAIR · GINI

公平性 · 工时分布

全员工时基尼、各组 σ、值勤天数分布；周末 / 夜航 / 早班占比日常监控。

QUAL-MON

资质监控

体检将到期、新机长任务含教员同组数、特殊机场供需比表。

RISK-DRIVE

风险驱动韧性

FDP 余量均值、晚→早连飞、过站<50 分、FO 单点脆弱任务抽样；每日空洞火花线。
